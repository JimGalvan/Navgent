# Reprobe visual system

Authority: the supplied New reproduction, Live run viewer and Evidence report HTML screens. Extend the same identity to public/account pages.

- Ground `#0c0c0d`; secondary surface `#121214`; dividers `#29292d`.
- Foreground `#ececea`; secondary text `#a0a09b`.
- Primary actions `#c6f24e`; observed failure/destructive actions `#ff8a7e`.
- Geist for text; Geist Mono for measured data, URLs, IDs and timestamps. Fonts are local and include their license.
- Forms, navigation, and lists use open space and restrained dividers. Primary controls have a small 4px radius and a 48px minimum height.
- Shared header: wordmark plus New / Live / Reports in the application, login/registration actions on public pages.
- Collapse split layouts into one column at narrower widths. Keep long URLs, outputs and filenames from overflowing.
- Clearly identify fixtures. Real screens must not imply unimplemented sandbox guarantees, media analysis, or verified reproduction outcomes.
