# Reprobe

Reprobe helps developers reproduce a reported web bug, watch Navgent execute the attempt, and inspect the resulting evidence in a private account workspace.

The application includes WorkOS email/password accounts and reproduction from written steps, screenshots, screen recordings, or a combination. Navgent reads the submitted evidence before execution and saves a reproduction brief and labeled key frames. Real results must distinguish user claims, observed behavior, execution status, and verified reproduction verdicts.

The first successful journey is register/login, submit a URL and bug evidence, follow a live run, and reopen the saved result. The design authority is the supplied Reprobe HTML mock. Public landing pages explain the product; application screens prioritize completing the task and reading evidence. Responsive behavior and keyboard access are required.
