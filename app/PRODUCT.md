# Reprobe

Reprobe helps developers reproduce a reported web bug, watch Navgent execute the attempt, and inspect the resulting evidence in a private account workspace.

The immediate delivery includes WorkOS email/password accounts, written-step execution, and local media previews. Video and screenshot analysis is being implemented separately by Claude. Real results must distinguish user claims, observed behavior, execution status, and verified reproduction verdicts.

The first successful journey is register/login, submit URL and steps, follow a live run, and reopen the saved result. The design authority is the supplied Reprobe HTML mock. Public landing pages explain the product; application screens prioritize completing the task and reading evidence. Responsive behavior and keyboard access are required.
